Act as a Senior Full-Stack PHP Developer and Database Architect. Build a comprehensive, enterprise-grade School Enrollment System using strictly Native Vanilla PHP (no frameworks like Laravel/Symfony) and a PostgreSQL database. 

You must strictly use Replit's built-in PostgreSQL environment, connecting via PDO by parsing the `DATABASE_URL` environment variable. Do not write Python, Node.js, or Docker configurations.

CRITICAL PROJECT CONSTRAINTS:
1. Architectural Style: Modular, clean PHP. Split the layouts cleanly into reusable include fragments: `header.php`, `sidebar.php`, `footer.php`, and a central database configuration file `db_connect.php`. Use semantic HTML structures so dynamic PHP variables can easily replace mock data.

### STEP 1: PostgreSQL DATABASE SCHEMA & INJECTION
Create a SQL migration file (`schema.sql`) and run it against the integrated Postgres instance to set up the following relational tables:
- `users`: id, email, password_hash, full_name, role (admin, admission, registrar, teacher, student), status, created_at
- `students`: id, user_id, student_number, enrollment_status (pending, verified, enrolled), academic_year, current_load_id
- `enrollment_queue`: id, student_id, document_url, verification_remarks, reviewed_by, updated_at
- `classes_and_schedules`: id, subject_code, subject_name, teacher_id, schedule_grid, room, capacity, enrolled_count

### STEP 2: MULTI-ROLE AUTHENTICATION PORTAL
- Build a dedicated, standalone login view separate from the main dashboard.
- Create a clean split-screen layout: the left panel handles school branding/news highlights, and the right panel features the authentication card.
- Include a Role Selector (Dropdown or Tabs for Admin, Admission, Registrar, Teacher, Student) that dictates the PHP session handling upon authentication.
- Secure logins using PHP's `password_verify()` against the PostgreSQL user records.

### STEP 3: MASTER LAYOUT ENGINE (Left Sidebar + Top Header)
Once an authenticated session is active, route users to a unified master layout that dynamically loads views based on their logged-in role badge:
- Top Bar: Displays global search, active Academic Year indicator ("A.Y. 2026–2027"), notification icon, and user profile snippet with a secure `logout.php` action.
- Left Sidebar Navigation: Generates dynamic navigation links tailored specifically to the active role. Include these 5 distinct configurations with dedicated CSS variable color accents:
  * Admin View (Accent: Dark Slate/Neutral): System logs table, user account creation form, global settings toggle.
  * Admission View (Accent: Royal Blue #2563EB): Applicant verification queue table, interactive document reviewer modal framework.
  * Registrar View (Accent: Emerald Green #059669): Official student masterlist with filtering tabs, sectioning grid, subject allocation control.
  * Teacher View (Accent: Teal #0D9488): Active class rosters, grade encoding spreadsheet-style input view, schedule matrix.
  * Student View (Accent: Sky Blue #0284C7): Multi-step digital enrollment wizard, study load schedule display, application status tracking card.

Ensure all layout components are fully responsive with mobile-friendly drawers and horizontally scrollable tables. Start by generating the database configuration (`db_connect.php`), the base database schema, and the login page architecture first.
